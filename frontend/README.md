# FinPro

A full-stack Financial Management & Risk Monitoring System built using Django REST Framework, React, and MySQL.

## Features

* JWT Authentication
* Income & Expense Tracking
* Budget Management
* Financial Dashboard
* Analytics & Charts
* Financial Alerts
* Risk Score Calculation
* AI-Based Financial Insights

## Tech Stack

### Frontend

* React
* Tailwind CSS
* Recharts

### Backend

* Django
* Django REST Framework
* JWT Authentication

### Database

* MySQL

## Modules

* Dashboard
* Transactions
* Budgets
* Analytics
* Alerts

## Installation

### Backend

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
npm install
npm run dev
```
